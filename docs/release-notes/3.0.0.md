EarControl 3.0.0 moves the main window and Practice deck to native Rust. It uses one process and removes the WebView2 runtime requirement. This release also adds a saved accent color and improves input recovery and Practice keyboard navigation.

## Install or migrate

Use the portable ZIP or per-user installer on Windows 10/11 x64 with a working OpenGL driver. The binaries are unsigned. The SHA-256 manifest covers the application executable and both packages.

If you installed 2.x, uninstall it in Windows Settings with **Delete app data** unchecked, then install 3.0. The new version reads your existing profiles. Hosted Windows VM checks verified clean install, migration from the published 2.1.2 installer, and profile preservation through uninstall.

## Benchmarks against 2.1.2

| Metric | Published 2.1.2 | 3.0.0 candidate | Change |
| --- | ---: | ---: | ---: |
| Executable | 3.26 MiB | 2.28 MiB | 30.1% smaller |
| Portable ZIP | 1.47 MiB | 1.21 MiB | 18.0% smaller |
| Installer | 1.22 MiB | 1.00 MiB | 18.0% smaller |
| Median idle private memory | 224.89 MiB | 97.32 MiB | 56.7% lower |
| Median idle summed working set | 404.65 MiB | 103.94 MiB | 74.3% lower |
| Median time to enabled Practice deck button | 581.69 ms | 275.02 ms | 52.7% sooner |
| Median time to titled main window | 61.84 ms | 309.18 ms | 247.34 ms later |
| Processes | 7 | 1 | 6 fewer |

These are paired Windows 11 measurements on one Ryzen 9 7940HS system. The native renderer waits through its first frame before showing its window. The Practice deck button was measured through Windows UI Automation. Physical headphone-to-action latency remains unmeasured.
