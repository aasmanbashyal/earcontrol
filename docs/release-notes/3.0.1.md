Clicking **Practice deck** now opens and focuses the deck and starts control for that window. The deck shows whether control is active and displays a larger slide number.

The target-window picker refreshes titles as you open it and type a search. Results stay open while you type, and you can scroll through long lists.

Download the installer or portable ZIP for Windows 10/11 x64. Both require a working OpenGL driver. The binaries are unsigned. Use the attached SHA-256 manifest to verify your download.

If you installed 2.x, uninstall it in Windows Settings with **Delete app data** unchecked. Then install 3.0.1 to use your existing profiles.
