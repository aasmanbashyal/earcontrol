# Getting help

Start with [the user guide](docs/user-guide.md). For missed commands, open Monitor first and check Activity. Pause competing media applications and select EarControl in Windows media controls. Keep the chosen target window in front and release physical modifier keys before controlling it.

For a bug report, include:

- EarControl version, Windows version, and portable or installed build.
- Headphone model and connection method for capture problems.
- Steps to reproduce, expected result, and actual result.
- Whether Monitor sees the command and what Activity reports.
- Whether the practice deck works with the same mapping.

Review screenshots and exported settings before sharing them. Remove personal window titles and text macros. Report reproducible application defects through the repository's Issues tab once the repository is hosted. Physical headphone compatibility may depend on the device firmware, driver, and Windows media routing.
