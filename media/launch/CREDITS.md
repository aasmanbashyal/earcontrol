# Demo credits

The demo shows actual EarControl browser UI. The practice sequence uses keyboard Right to advance the deck and is labeled as an illustrated walkthrough. It is not a physical headphone test.

## Sound and runtime

- `click2.ogg` and `impactSoft_medium_001.ogg`: Kenney, [CC0](https://kenney.nl/), from the brag plugin's bundled sound library.
- Opening title motion adapted from Hyperframes' `blur-in` registry component. The rendered composition uses Hyperframes 0.9.19 and GSAP 3.15.0. The local GSAP runtime retains its distribution license notice.
- Video titles use Open Sans; the captured UI retains the application's Windows system-font appearance. Hyperframes resolves the title font. Its cached font files are not added to the application bundle.
- Product screenshots and the EarControl logo come from this repository. No stock people, customer data, or private target-window names are included.
