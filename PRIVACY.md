# EarControl privacy policy

EarControl runs on your Windows PC. The app does not require an account, include analytics or advertising, or send your profiles, input, or device information to the developer.

## What EarControl uses

- EarControl reads the titles of available windows so you can select a target. It uses Windows media commands and, when enabled, supported keyboard media keys to run the actions you choose. Shortcut recording reads the chord you enter while the recording control has focus.
- The Devices screen lists compatible paired Bluetooth devices reported by Windows. EarControl does not record audio or use your microphone.
- EarControl stores your settings, mappings and any text you add to macros as a local JSON file under your Windows user profile. Activity, the selected target and the current control session are held in memory while the app runs. EarControl sends your configured keystrokes and macro text to the active target you select. What that target app does with the input is governed by that app.

## Your controls

Use **Stop** or close EarControl to end capture. You can turn off keyboard media-key capture in Settings, clear Activity, and edit or remove saved profiles. Settings can export your profiles to a JSON file you choose. Exported files can contain macro text. Keep them private if they contain information you do not want to share. You can delete exports yourself and remove saved settings by deleting `profiles.json` with EarControl closed. If you use the Store edition, Windows manages its packaged data and can clear it when you reset or uninstall the app.

If you contact the developer on GitHub, you choose what information to share. Public issues are visible to other people. Remove personal window titles and private macro text from screenshots or files before attaching them. For privacy questions, use the [EarControl GitHub Issues page](https://github.com/aasmanbashyal/earcontrol/issues).
